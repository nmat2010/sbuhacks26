# Wolfie Sensei Web App

React web app for tablets and iPad. Provides a canvas-based notebook with Wolfie's help.

**Owner:** Thu (Phases 10, 11, 12)

## Features

- HTML5 Canvas drawing notebook
- Wolfie mascot widget with hints
- Web Speech API for voice (on-device)
- Camera API for photographing physical paper
- WebSocket sync with desktop
- IndexedDB for offline storage
